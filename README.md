# 自己分析診断アプリ

転職活動や自己理解に役立つ、日本語の自己分析Webアプリケーションです。

## 概要

10の質問に答えることで、あなたの人材タイプを診断します。結果として以下の4つのタイプのいずれかが判定されます：

- **👑 リーダータイプ**: 決断力と実行力に優れ、チームを導く力がある
- **🤝 サポータータイプ**: 共感力が高く、周囲との調和を大切にする
- **🎨 クリエイタータイプ**: 創造性豊かで、新しいアイデアを生み出す
- **📊 アナリストタイプ**: 論理的思考に優れ、データに基づいた判断ができる

## 機能

- 📝 10問の選択式質問
- 📊 リアルタイムの進捗表示
- 🎯 4つの人材タイプ診断
- 💡 各タイプの強み・適職・アドバイスの表示
- 📱 レスポンシブデザイン（スマートフォン対応）

## 使い方

1. ブラウザで `index.html` を開く
2. 「診断を始める」ボタンをクリック
3. 10個の質問に順番に回答
4. 診断結果を確認

## カスタマイズ

### 質問を追加・変更

`script.js` の `questions` 配列を編集してください：

```javascript
const questions = [
    {
        question: "質問文",
        answers: [
            { text: "回答1", type: "leader" },
            { text: "回答2", type: "supporter" },
            // ...
        ]
    },
    // ...
];
```

### 人材タイプを変更

`script.js` の `talentTypes` オブジェクトを編集してください：

```javascript
const talentTypes = {
    leader: {
        name: "タイプ名",
        emoji: "絵文字",
        description: "説明",
        strengths: ["強み1", "強み2", ...],
        careers: ["職種1", "職種2", ...],
        advice: "アドバイス"
    },
    // ...
};
```
