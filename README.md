# MBTI性格診断アプリ

転職活動やキャリア開発に役立つ、MBTI理論に基づいた日本語の性格診断Webアプリケーションです。

## 概要

MBTI（Myers-Briggs Type Indicator）理論に基づいた16の質問に答えることで、あなたの性格タイプを診断します。

### 4つの指標

1. **E（外向）/ I（内向）** - エネルギーの方向性
2. **S（感覚）/ N（直観）** - 情報の収集方法
3. **T（思考）/ F（感情）** - 意思決定の基準
4. **J（判断）/ P（知覚）** - 生活スタイル

### 16の性格タイプ

これらの組み合わせにより、以下の16タイプのいずれかが判定されます：

#### アナリスト
- **INTJ（建築家）** - 戦略的思考に優れた独立心の強いリーダー
- **INTP（論理学者）** - 分析的で理論的思考に優れた革新者
- **ENTJ（指揮官）** - 大胆で強い意志を持つリーダー
- **ENTP（討論者）** - 機知に富み、革新的なアイデアを生み出す

#### 外交官
- **INFJ（提唱者）** - 理想主義的で深い洞察力を持つ
- **INFP（仲介者）** - 理想主義的で創造的、深い価値観を持つ
- **ENFJ（主人公）** - カリスマ的で人々を導く力がある
- **ENFP（運動家）** - 熱意があり創造的で社交的

#### 番人
- **ISTJ（管理者）** - 実用的で信頼性が高く、責任感が強い
- **ISFJ（擁護者）** - 献身的で温かく、他者を守る
- **ESTJ（幹部）** - 組織力があり実務的なリーダー
- **ESFJ（領事）** - 思いやりがあり協調性が高い

#### 探検家
- **ISTP（巨匠）** - 実践的で論理的、問題解決が得意
- **ISFP（冒険家）** - 芸術的で柔軟性があり、現在を大切にする
- **ESTP（起業家）** - エネルギッシュで行動的、リスクを恐れない
- **ESFP（エンターテイナー）** - 社交的で楽しいことが大好き

## 機能

- 📝 40問の質問（5段階評価形式）
- 📊 リアルタイムの進捗表示
- ⬅️ 戻るボタンで前の質問に戻れる
- 🎯 16の性格タイプ診断
- 📈 各指標の詳細スコア表示（パーセンテージ）
- 💡 各タイプの詳細情報
  - 性格の特徴
  - 強み
  - 適した職種・役割
  - 成長のためのアドバイス
- 📱 レスポンシブデザイン（スマートフォン対応）

## 使い方

1. ブラウザで `index.html` を開く
2. 「診断を始める」ボタンをクリック
3. 40個の質問に順番に回答（各質問は5段階評価）
   - 非常に同意する：+2点
   - やや同意する：+1点
   - どちらでもない：0点
   - やや同意しない：-1点
   - 非常に同意しない：-2点
4. 必要に応じて「戻る」ボタンで前の質問に戻れます
5. 診断結果（4文字のタイプコードと詳細スコア）を確認

## 診断の仕組み

各質問は4つの指標（E/I、S/N、T/F、J/P）のいずれかを測定します：

- **E/I**: 各10問（外向性 vs 内向性）
- **S/N**: 各10問（感覚 vs 直観）
- **T/F**: 各10問（思考 vs 感情）
- **J/P**: 各10問（判断 vs 知覚）

### スコアリング方式

5段階評価で回答し、各回答には以下のポイントが割り当てられます：
- 非常に同意する：+2点
- やや同意する：+1点
- どちらでもない：0点
- やや同意しない：-1点
- 非常に同意しない：-2点

各軸でスコアが高い方の文字を組み合わせて、4文字のタイプコード（例：INFJ、ENTP）を判定します。

また、結果画面では各指標のパーセンテージも表示されるため、より詳細な自己理解が可能です。

## カスタマイズ

### 質問を追加・変更

`script.js` の `questions` 配列を編集してください：

```javascript
{
    question: "質問文",
    answers: [
        { text: "回答1", dimension: "E" },  // E, I, S, N, T, F, J, P のいずれか
        { text: "回答2", dimension: "I" }
    ]
}
```

### タイプの説明を変更

`script.js` の `personalityTypes` オブジェクトを編集してください：

```javascript
"INTJ": {
    name: "タイプ名",
    nickname: "ニックネーム",
    emoji: "絵文字",
    description: "説明",
    strengths: ["強み1", "強み2", ...],
    careers: ["職種1", "職種2", ...],
    advice: "アドバイス"
}
```

## MBTI理論について

MBTI（Myers-Briggs Type Indicator）は、カール・ユングの心理学的類型論を基にしたキャサリン・クック・ブリッグスとイザベル・ブリッグス・マイヤーズが開発した性格診断です。

**注意**: この診断は教育・自己理解を目的としたものです。正式なMBTI診断を受けたい場合は、認定プラクティショナーにご相談ください。
